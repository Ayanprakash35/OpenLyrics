## Adding a video

GitHub plays videos uploaded through its editor: on github.com, open `README.md`, click edit, and
drag the `.mp4` where its marker is. GitHub uploads it and inserts a link that renders as a player.
Files up to 100 MB; under 10 MB loads quickly. Committing `.mp4` files to the repo works too, but
they then only show as links.

## Recording tips

- macOS **Screenshot** app (⇧⌘5) › Record Selected Portion; for the lock screen, record with an
  iPhone, since screen recording pauses while the Mac is locked.
- Pick songs whose covers have strong, different colors, so the album colors show.
- Keep clips short and trim the start and end.
- Screenshots: PNG, at least 1600 px wide.
